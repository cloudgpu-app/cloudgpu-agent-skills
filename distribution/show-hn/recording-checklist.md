# Full product demonstration acceptance checklist

This is production filming preparation, not HN submission text. HN requires owner-authored words and manual submission. The existing 19.4-second video is a read-only UI tour, not this complete execution recording.

## Required continuous evidence

1. The agent receives a bounded task, such as the already-verified GPU environment script. Show the workload and intended result, without private files.
2. Fetch current readiness/task fit and a current estimate. Show billing scope, expiry, minimum/increment and the balance needed to start. Do not reuse the historical dollar amounts as today's quote.
3. The owner completes actual client/browser authorization and reviews the spending/runtime/data/output limits. Pause recording over login or redact account identifiers; never record secrets, device codes or a returned key. Do not simulate an approval screen and label it real.
4. The owner explicitly approves the actual paid workload and current binding terms. An account connection is a separate event, not approval to allocate. Whole-hour offers require their own accepted billing quote.
5. Submit the reviewed idempotent Job once and capture its receipt. Reconcile timeouts; do not start a replacement for an uncertain result.
6. Show terminal status and retrieve the requested environment report. Verify byte count and SHA-256; retain the output according to the agreed storage terms.
7. Show the finalized GPU fee and platform release confirmation. If independent upstream release evidence is unavailable, label it unknown rather than implying verification.
8. Show actual elapsed UTC time. Time-lapse edits must be labeled. Include storage/transfer separately, and retain any failed attempt's cost in the total.

- A real owner/client approval session suitable for filming, using a test account without customer data.
- A current quote and an explicitly approved remaining test budget. Existing internal acceptance fees are historical evidence, not an unlimited filming authorization.
- A secure credential store and a recording setup that excludes secret material.
